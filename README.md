# Minimalist MERN + Supabase Todo App (CRUD Demo)

A simple, clean, and minimalistic Todo web application built with the **MERN Stack architecture** and **Supabase (PostgreSQL)** designed specifically to demonstrate **CRUD** (Create, Read, Update, Delete) operations with clarity.

---

## 🛠️ Tech Stack Architecture

- **Frontend**: React (Vite) + Lucide Icons + Minimalist CSS
- **Backend API**: Node.js + Express
- **Database**: Supabase (PostgreSQL & Supabase Client `@supabase/supabase-js`)
- **API Communication**: REST API with endpoints mapped directly to CRUD operations

---

## 🔄 CRUD Operations Mapping

| Operation | HTTP Method | Route | Description | Supabase Method |
| :--- | :--- | :--- | :--- | :--- |
| **[C] Create** | `POST` | `/api/todos` | Add a new todo task | `supabase.from('todos').insert(...)` |
| **[R] Read** | `GET` | `/api/todos` | Retrieve all todo tasks | `supabase.from('todos').select('*').order(...)` |
| **[U] Update** | `PUT` | `/api/todos/:id` | Toggle completion status or edit title | `supabase.from('todos').update(...).eq('id', id)` |
| **[D] Delete** | `DELETE` | `/api/todos/:id` | Remove a todo task | `supabase.from('todos').delete().eq('id', id)` |

## 🚀 Step-by-Step Setup Guide

### 1. Database Setup in Supabase
1. Log into your [Supabase Dashboard](https://supabase.com/dashboard).
2. Open your project (or create a new free project).
3. Navigate to the **SQL Editor** tab from the left sidebar.
4. Copy the SQL script from [`supabase_setup.sql`](./supabase_setup.sql) and paste it into the query window:
   ```sql
   CREATE TABLE IF NOT EXISTS todos (
     id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
     title TEXT NOT NULL,
     is_completed BOOLEAN DEFAULT FALSE,
     created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
   );

   ALTER TABLE todos ENABLE ROW LEVEL SECURITY;

   CREATE POLICY "Allow public CRUD operations" 
   ON todos FOR ALL TO public USING (true) WITH CHECK (true);
   ```
5. Click **Run**. Your table is now initialized!

---

### 2. Configure Supabase Credentials
1. In your Supabase Dashboard, go to **Project Settings** -> **API** (or **Data API**).
2. Copy your **Project URL** and your **anon / public key** (or service role key).
3. Open [`backend/.env`](./backend/.env) and replace the placeholders:
   ```env
   PORT=5000
   SUPABASE_URL=https://your-project-ref.supabase.co
   SUPABASE_KEY=your-actual-anon-or-service-role-key
   ```

---

### 3. Run the Backend & Frontend

#### Terminal 1 (Backend Server):
```bash
cd backend
npm run dev
```
*Backend runs on `http://localhost:5000`*

#### Terminal 2 (React Frontend):
```bash
cd frontend
npm run dev
```
*Frontend runs on `http://localhost:5173`*
